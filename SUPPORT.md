# Getting help

1. Check the [user guide](docs/user-guide.md) and
   [troubleshooting](docs/troubleshooting.md).
2. Search the [issues](https://github.com/Okaza03/LinuxLink/issues), including
   closed ones.
3. Still stuck? [Open an issue](https://github.com/Okaza03/LinuxLink/issues/new/choose).
   Questions are welcome; please say which version you use, how you installed
   it and which distribution and desktop you run.

Found a security problem? Follow [SECURITY.md](SECURITY.md) instead.
